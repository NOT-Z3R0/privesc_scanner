# PrivEsc Scanner - Architecture Documentation

## System Architecture

### High-Level Design

The PrivEsc Scanner follows a **modular, object-oriented architecture** designed for:
- **Maintainability**: Each scan type is isolated in its own class
- **Extensibility**: Easy to add new scan modules
- **Readability**: Clear separation of concerns
- **Testability**: Individual components can be tested independently
